# 《小画家模拟器》

一个纯前端的临摹玩具：页面左右（窄屏上下）分成两半。左边放参考图，右边是一块同样尺寸的画布。你在右边顺着轮廓的方向随便画——**画的时候是你自己的线**；抬笔之后，这一笔会用大约一秒缓缓变形，贴到它盖住的参考轮廓上。空白处太远的一笔会淡出。把所有轮廓描一遍，就能复原整张线稿。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 `http://localhost:45217`）。

## 做成静态站点 / GitHub Pages

```bash
npm run build
```

产物在 `dist/`。生产构建默认 `base` 为 `/xiaohuajia/`（对应 https://sora233.github.io/xiaohuajia/）。也可用环境变量覆盖：

```bash
VITE_BASE=/xiaohuajia/ npm run build
```

推送到 `main` 或 `master` 后，`.github/workflows/deploy.yml` 会用官方 Pages Action 构建并发布。仓库 Settings → Pages 的 Source 请选 **GitHub Actions**。

## 怎么用

1. 上传一张图，或点「使用示例图」。
2. 在右侧沿某条轮廓的大致方向画一条晃线。松手之前一直是你的笔；松手后它会变形到对应的参考线上。一笔描完整段背线或耳廓，就会得到那一整条。
3. 「吸附距离」调的是能容下多大的偏移。周围没有够近的线时，笔迹会淡出（打开「显示原始笔迹」仍能看见淡淡的原稿）。
4. 「线条细节」控制提取多少轮廓。
5. 「参考图上色」用参考图像素给吸附后的笔画着色；默认是墨色。
6. 撤销 / 清空 / 下载 PNG。

支持鼠标、触摸和压感笔。图片只在本地处理。

## 矫正算法（简述）

这不是「笔刷扫过就揭开原图像素」，而是把 **这一笔本身** 变成贴在参考轮廓上的笔画：

1. **提取轮廓**  
   灰度 + 小高斯模糊 + Sobel。照片主要留梯度边；黑白线稿只用深色墨迹，避免一条线被描成双边。线稿里成片的网点只留外轮廓，实心黑块留边界，粗线再收成中心线，一两像素的断口先粘上。然后做 Zhang-Suen 细化得到单像素骨架，去掉短毛刺和贴在一起的重影，在分叉处拆成原子链。每个结点上优先把直线穿过去，直角拐弯也会接成同一条长线（大约超过 105° 的掉头才断开）。端点之间的小缺口同样会补上，包括拐角处的断开；两边都比较长、又几乎共线时，缺口可以再宽一些。折线会简化、轻度平滑，并按弧长重采样。重活在 Web Worker 里做，页面上会显示「处理中…」。

2. **绘画时**  
   笔迹原样留在画布上，不实时吸附。

3. **抬笔**  
   在附近的参考轮廓里，按形状和位置选最接近的一条，不要求这一笔和参考线一样长。目标是这一条上、从笔迹起点的投影走到终点投影的那一整段；线拐了弯就顺着拐，笔伸出端点就收到轮廓为止。整笔按弧长拉过去，不够长就拉开，太长就缩短（先短暂停住，笔下会淡淡标出将对上的那条线，再用缓入缓出大约 0.8 秒）。只有周围没有够近的线时，才把原稿淡出。打开「显示原始笔迹」可对照那条晃线。

4. **上色**  
   沿当前笔画取参考图像素；太接近纸色的点仍用墨色，避免线稿背景渗进笔画。变形结束后，颜色落在目标轮廓上。
