# 《小画家模拟器》

一个纯前端的临摹玩具：页面左右（窄屏上下）分成两半。左边放参考图，右边是一块同样尺寸的画布。你在右边顺着轮廓的方向随便画——每一笔都会被 **掰到最近的参考轮廓上**，变成贴着那条真线的干净笔画。空白处太远则不落墨。把所有轮廓描一遍，就能复原整张线稿。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 `http://localhost:45217`）。

## 做成静态站点 / GitHub Pages

```bash
npm run build
```

产物在 `dist/`。生产构建默认 `base` 为 `/xiaohuajia/`（对应 https://sora233.github.io/xiaohuajia/）。也可用环境变量覆盖：

```bash
VITE_BASE=/xiaohuajia/ npm run build
```

推送到 `main` 或 `master` 后，`.github/workflows/deploy.yml` 会用官方 Pages Action 构建并发布。仓库 Settings → Pages 的 Source 请选 **GitHub Actions**。

## 怎么用

1. 上传一张图，或点「使用示例图」。
2. 在右侧沿某条轮廓的大致方向画一条晃线。笔迹会吸附成该轮廓上、与你起止范围对应的一段。
3. 「吸附距离」是最大搜索半径：离线太远的乱涂会被丢掉（打开「显示原始笔迹」仍能看见淡淡的原稿）。
4. 「线条细节」控制提取多少轮廓。
5. 「参考图上色」用参考图像素给吸附后的笔画着色；默认是墨色。
6. 撤销 / 清空 / 下载 PNG。

支持鼠标、触摸和压感笔。图片只在本地处理。

## 矫正算法（简述）

这不是「笔刷扫过就揭开原图像素」，而是把 **这一笔本身** 变成贴在参考轮廓上的笔画：

1. **提取轮廓**  
   灰度 + 小高斯模糊 + Sobel。照片主要留梯度边；偏亮的线稿再并上深色墨迹。然后做 Zhang-Suen 细化得到单像素骨架，沿骨架追踪成分叉处断开的折线，并建空间网格索引。

2. **绘画时（实时）**  
   每个输入点在「吸附距离」内找最近的轮廓点；前几笔锁定一条主轮廓。按输入顺序把投影下标沿轮廓展开（闭环会按行进方向解缠），取从起点投影到终点投影的子路径，立刻画成笔画。所以你看到的是线在「贴上去」，不是一块窗口。

3. **抬笔**  
   用整段输入再算一次子路径并落笔。空白处命中率太低则丢弃吸附结果。打开「显示原始笔迹」可对照那条晃线。

4. **上色**  
   沿吸附路径取参考图像素；太接近纸色的点仍用墨色，避免线稿背景渗进笔画。
